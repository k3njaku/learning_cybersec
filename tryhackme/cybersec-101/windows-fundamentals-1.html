Windows Fundamentals 1

Your first real tour of Windows — editions, the desktop, NTFS, user accounts, UAC, Control Panel, and Task Manager.

"Windows runs on 75% of desktops worldwide. That also makes it the #1 malware target on the planet. Know your enemy — even if it's your own OS." 🪟

⚡ What you'll actually learn

the concepts
Concept 01 // Windows editions

🪟 Windows editions — not all Windows is created equal

A quick time-travel through Windows versions, and why the edition installed on your target matters for pentesting.

The Windows family tree, speed-run:

XP (2001, the legend) → Vista (2006, the disaster — everyone hated UAC's first implementation) → 7 (2009, universally loved) → 8 (2012, tiles nobody asked for) → 10 (2015, "the last version of Windows"... until it wasn't) → 11 (2021, rounded corners and a centered taskbar).

But here's the thing that actually matters for you as a pentester: editions within each version.

📝 Think of Windows editions like gym memberships

Home gets you in the door — you can browse the web, run apps, exist. Pro gets you the sauna, personal trainer, and the locker with the combination lock.

Pro has BitLocker (full-disk encryption), Remote Desktop (host), and Group Policy Editor (gpedit.msc). Home has NONE of these.

🏠 Windows Home

  • Basic desktop experience
  • Windows Defender
  • Device encryption (watered-down)
  • ❌ No BitLocker
  • ❌ No Remote Desktop (host)
  • ❌ No Group Policy Editor
  • ❌ No Hyper-V

💼 Windows Pro

  • Everything in Home, plus:
  • ✅ BitLocker (full-disk encryption)
  • ✅ Remote Desktop (host — others can RDP to you)
  • ✅ Group Policy Editor (gpedit.msc)
  • ✅ Hyper-V (built-in hypervisor)
  • ✅ Windows Sandbox
  • ✅ Domain join (Active Directory)
💡 Room context: The VM in this THM room runs Windows Server 2019 Standard. Creds: administrator / letmein123!. Server editions have all Pro features and more (AD DS, DNS, DHCP, etc.).
Concept 02 // The desktop and GUI

🖥️ The desktop — 7 things you see every day (but never think about)

The Windows desktop is made up of specific components, and knowing their names matters when you're reading recon notes, writing reports, or following attack guides.

🖼️Desktop

The background area. Shortcuts live here. Right-click for display settings.

🪟Start Menu

Click the Windows icon. Quick shortcuts (left), app list (middle), live tiles (right).

🔍Search Box

Next to Start. Search apps, settings, files, and the web. Cortana lived here once.

📋Task View

Virtual desktops + timeline. Separate your work from your... "research."

📌Taskbar

The bar at the bottom. Pinned apps + running apps. Right-click it for customization gold.

🔧Toolbars

Optional extras you can add to the taskbar (Address, Links, Desktop). Rarely used.

🔔Notification Area

Bottom-right: clock, network, volume, Action Center. Plus hidden icons (click the ^).

Start Menu anatomy

The Start Menu has three zones:

  • Left column: Quick shortcuts — your account, Documents, Pictures, Settings, Power
  • Middle column: Alphabetical list of ALL installed apps
  • Right area: Pinned tiles / live tiles (weather, news, etc.)

Taskbar tricks

Right-click the taskbar for a context menu with:

  • Toolbars — add an address bar, links bar, or desktop toolbar
  • Search → choose Hidden / Show search icon / Show search box
  • Show Task View button — toggle on/off
  • Taskbar settings — open the full settings panel
💡 Notification Area deep dive: Besides the clock and network icon, you'll see Action Center (the flag/speech-bubble icon). Click the ^ arrow to show hidden system tray icons — that's where AV agents, VPN clients, and background services live.
Concept 03 // The file system

📂 NTFS — the file system that actually does stuff

Before NTFS, Windows used FAT16 and FAT32. They were simple. Too simple. NTFS is what makes Windows a serious operating system.

📝 FAT vs NTFS = a shed vs a bank vault

FAT is a garden shed. One lock, no camera, no alarm. Anybody who walks in can take whatever they want. NTFS is a bank vault — security cameras (journaling), individual safety deposit boxes (file-level permissions), hidden compartments (ADS), and a guard at the door (encryption).

If your drive is still FAT32 in 2026, you're either running a USB stick or you have bigger problems.

NTFS vs FAT — the comparison that matters

✅ NTFS can...

  • Set per-file / per-folder permissions
  • Handle files larger than 4 GB
  • Journal changes (crash recovery)
  • Encrypt files (EFS)
  • Compress files at the filesystem level
  • Store Alternate Data Streams (ADS)
  • Support very large volumes (256 TB+)

❌ FAT32 can't...

  • No file-level permissions at all
  • Max file size: 4 GB (try downloading a VM image...)
  • No journaling (crash = possible corruption)
  • No encryption
  • No compression
  • No ADS
  • Max volume: 2 TB

NTFS permissions table

Right-click any file/folder → Properties → Security tab. You'll see these:

PermissionWhat it lets you do
Full ControlRead, write, execute, delete, change permissions, take ownership. The keys to the kingdom.
ModifyRead, write, execute, delete. Everything except changing permissions.
Read & ExecuteView file contents and run executables. Standard for program folders.
List Folder ContentsSee what's inside a folder (but not necessarily read the files). Folders only.
ReadView file contents and attributes. Read-only access.
WriteCreate new files/folders. Modify existing file data. Can't delete.

🕵️ Alternate Data Streams (ADS) — the hidden layer

This is the spicy part. NTFS lets you attach hidden data streams to any file. A file called report.pdf could have a completely separate data stream called report.pdf:evil.exe attached to it — and Windows Explorer won't show it.

Legitimate uses: Windows uses ADS for "Zone Identifiers" (marking files downloaded from the internet). But malware authors? They use ADS to hide entire payloads inside innocent-looking files.

# Create an ADS (for demo purposes) echo "hidden payload" > innocent.txt:secret.txt # Read it back more < innocent.txt:secret.txt # List ADS on a file dir /R innocent.txt # Or in PowerShell: Get-Item innocent.txt -Stream *
🧠 Brain Power
Why would malware authors use Alternate Data Streams instead of just hiding a file in a deep folder somewhere?

Three reasons: (1) ADS are invisible to Windows Explorer — there's no file to see, no size increase to notice. A user could right-click a file and check Properties and the file size wouldn't include the ADS. (2) Many antivirus scanners historically didn't scan ADS (modern ones do, but it's still a blind spot for basic tools). (3) ADS survive file copies on NTFS volumes — the hidden stream travels with the host file. It's steganography at the filesystem level.

Concept 04 // Windows\System32

⚙️ The Windows folder and System32

The C:\Windows folder is where the OS lives. And inside it, System32 is the crown jewels.

The Windows folder location is stored in the environment variable %windir%. By default, that's C:\Windows. You can verify:

# In CMD: echo %windir% # Output: C:\Windows # In PowerShell: $env:windir

System32 contains ~3,975 items — critical DLLs, system executables, drivers, and config files. The OS literally cannot function without this folder.

🚨 DO NOT delete System32. This is not a meme warning — it's real. Deleting or corrupting System32 will brick Windows entirely. No boot, no recovery, no mercy. On a pentest, be careful when running cleanup scripts that might touch system directories. On your own machine, obviously just don't.
Concept 05 // User accounts & profiles

👤 User accounts — who are you on this machine?

Windows has two main account types. Understanding the difference is critical for privilege escalation.

👑 Administrator

  • Can add/delete user accounts
  • Can modify groups and group membership
  • Can change system-wide settings
  • Can install software for all users
  • Can access any file on the system
  • Full control over the machine

👤 Standard User

  • Can only modify their own files
  • Cannot install system-wide software
  • Cannot change system settings
  • Cannot add/remove other users
  • Limited to their own profile folder
  • Needs UAC elevation for admin tasks

Profile folders

Every user gets a profile at C:\Users\<username>\ containing:

C:\Users\administrator\ ├── Desktop\ ├── Documents\ ├── Downloads\ ├── Music\ ├── Pictures\ └── Videos\

Managing users: lusrmgr.msc

Open the Run dialog (Win+R) and type lusrmgr.msc — this opens Local User and Group Management. Two folders:

  • Users — every local account on the machine. Double-click one to see its properties (full name, description, group membership, password settings).
  • Groups — built-in groups like Administrators, Users, Guests, Remote Desktop Users. Membership in these groups determines what you can do.
💡 The Guest account: A built-in account meant for temporary access with zero privileges. It's disabled by default on modern Windows — but always worth checking during recon. If someone enabled it... that's a finding.
Concept 06 // User Account Control

🛡️ UAC — the popup everyone clicks "Yes" on

Why does it exist? Because most home users run as admin. And when admin = default, every piece of malware you accidentally run ALSO runs as admin.

📝 Think of UAC like a bouncer at a VIP door

You're on the guest list (admin account), but you still have to show ID every time you want into the VIP section (elevated privileges). The bouncer is UAC. Most people just flash their badge and walk through without thinking — but the bouncer exists so that if someone ELSE tries to sneak in using your ticket, they get stopped.

UAC doesn't ask "are you admin?" — it asks "are you SURE you want admin powers RIGHT NOW?"

How UAC actually works

  1. You log in with an admin account. But your processes run with standard privileges by default.
  2. An app needs elevated access (install software, modify system files, change registry).
  3. Windows shows the UAC consent prompt — "Do you want to allow this app to make changes to your device?"
  4. You click Yes → the app gets a new elevated token with full admin rights.
  5. You click No → nothing happens. The app stays standard-privilege.

The shield icon 🛡️ on an executable or button means "this action will trigger a UAC prompt." You'll see it on installers, system settings, and anything that touches protected areas.

⚠️ Exception: The built-in Administrator account (the one literally named "Administrator") has UAC disabled by default. Every process it runs is fully elevated. This is why landing on the built-in Admin account during a pentest is basically game over — no UAC bypass needed.
🧠 Brain Power
You're pentesting a Windows box and find a Standard User account. The user clicks a program that has a shield icon. What happens?

Unlike an admin account (which gets a simple "Yes/No" consent prompt), a Standard User gets a credentials prompt — Windows asks for an administrator username and password. If the standard user doesn't know admin creds, they simply can't run the elevated program. This is WHY standard user accounts are more secure than admin accounts — they can't "Yes" their way through UAC.

Concept 07 // Settings vs Control Panel

🎛️ Two places for settings — the old way and the new way

Windows has two settings interfaces. They overlap, they redirect to each other, and they're both still here in 2026. Welcome to Microsoft.

🖥️ Control Panel (the OG)

  • Been around since Windows 3.1 (1992)
  • More detailed, more options
  • Multiple views: Category, Large Icons, Small Icons
  • Programs and Features — shows ALL installed software + exact versions (recon gold)
  • Still has settings that Settings app doesn't

⚙️ Settings (the new kid)

  • Introduced in Windows 8
  • Touch-friendly, simplified, modern UI
  • Organized by category (System, Devices, Network, etc.)
  • Some pages just redirect to Control Panel anyway
  • Microsoft wants this to replace Control Panel... eventually
💡 Pentest gold: Control Panel → Programs and Features shows every installed program with its name, publisher, and version number. This is a treasure map for finding outdated software with known CVEs. On a post-exploit enumeration, this is one of the first things to check (or wmic product get name,version from the command line).
Concept 08 // Task Manager

📊 Task Manager — your first forensics tool

Right-click the taskbar → Task Manager. Or hit Ctrl+Shift+Esc. This is the single most useful built-in diagnostic tool on Windows.

Task Manager has two modes:

  • Simple View: Just a list of running apps with an "End task" button. What normies see.
  • More Details: Click "More details" at the bottom to unlock the REAL Task Manager with multiple tabs.

The tabs that matter

📋 Processes

Every running app + background process with CPU, memory, disk, and network usage. Sort by CPU to find what's hogging your system.

📈 Performance

Live graphs for CPU, memory, disk, network, GPU. Great for spotting crypto miners or exfiltration spikes.

👥 Users

Who's logged in and what they're running. Multi-user servers show all active sessions.

🔍 Details

Raw process list with PID, status, username, CPU, memory. The "Processes" tab but without the pretty grouping. More data, more columns.

⚙️ Services

All Windows services with their status (Running/Stopped). Right-click to start, stop, or open the full Services console.

🚀 Startup

Apps that launch at boot. Disable the ones you don't need. Malware LOVES to add itself here for persistence.

🧠 Brain Power
Why is Task Manager the first thing a malware analyst opens when investigating a suspicious machine?

(1) Unusual processes — malware often runs as a process with a suspicious name (like svchost.exe running from the wrong directory, or chrome.exe when Chrome isn't installed). (2) High CPU/network usage — crypto miners spike CPU; data exfiltration spikes network. (3) Unknown startup entries — persistent malware adds itself to startup. (4) Process tree — seeing WHAT launched WHAT helps trace the infection chain (e.g., Word → PowerShell → cmd.exe = classic macro malware). Task Manager is triage step zero before breaking out Process Monitor, Process Explorer, or a full memory dump.
