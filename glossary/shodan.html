Chapter 01 // Definition

📖 What is Shodan?

Shodan is a search engine for internet-connected devices. While Google crawls web pages (HTML, text, links), Shodan crawls IP addresses — connecting to 200+ ports on every public IP and saving the service banners that come back.

A service banner is the "hello, I'm…" message a server sends when you connect. It reveals what software is running, what version, sometimes the OS, sometimes even default credentials left in the response.

Shodan stores all of this in a searchable database. That means you can ask questions like:

  • "Show me every WordPress site in Germany"
  • "Find all MongoDB databases with no authentication"
  • "List every Apache 2.4.49 server" (the path traversal CVE)
  • "Show webcams running on port 554 in Brazil"

📝 The night-drive analogy

Imagine driving down every single street in a city at night, slowly, with a notepad. Every house with its lights on — you write down what you can see through the windows. "House #42 has a Samsung TV, a Nest thermostat, and the front door is unlocked."

You're not breaking in. You're just looking. But now you have a directory of every house, what's inside, and which ones forgot to lock the door.

That's Shodan. It drives down every IP address, knocks on 200+ ports, and writes down what answers. The scary part? It does this for the entire internet. Continuously.

how it works
Chapter 02 // Under the hood

⚙️ How Shodan crawls the internet

1. Scan every IP

Shodan's crawlers connect to all ~4.3 billion IPv4 addresses on 200+ common ports (22, 80, 443, 3306, 8080, 27017, etc.). No DNS needed — just raw IPs.

2. Grab the banner

When a port responds, Shodan saves the service banner — the first bytes the server sends. This reveals software name, version, config, sometimes even data.

3. Index & search

Banners get indexed with metadata: IP, port, country, org (ASN), hostnames, SSL certs, HTTP headers, HTML titles. You search this database like Google.

💡 Key insight: Shodan doesn't exploit anything. It just connects and records what's publicly visible. If your MongoDB is exposed on port 27017 with no auth, that's YOUR misconfiguration — Shodan just noticed it. So did every attacker.

Chapter 03 // Getting started

⚡ Install the Shodan CLI

Shodan has a web UI at shodan.io, but the CLI is where the real power lives.

# Step 1: Install via pip (use a venv!) pip install shodan # Step 2: Initialize with your API key (grab from account.shodan.io) shodan init YOUR_API_KEY # Step 3: Verify it works shodan info
💡 Free account: Create one at shodan.io — you get an API key immediately. Free tier is limited (100 results per search, no filters like vuln:), but enough to learn. The $49 one-time membership unlocks everything.

Chapter 04 // Essential commands

🛠️ The 5 most useful Shodan CLI commands

# 1. SEARCH — find devices matching a query shodan search "apache country:US port:443" # 2. HOST — deep-dive on a single IP (ports, vulns, history) shodan host 8.8.8.8 # 3. DOMAIN — DNS records + subdomains for a domain shodan domain example.com # 4. COUNT — how many results match a query (no results shown) shodan count "product:nginx country:DE" # 5. STATS — breakdown by top countries, orgs, ports, etc. shodan stats "http.html:wp-content"

search is your bread and butter. host is for target deep-dives. domain expands attack surface during recon. count and stats help you scope how big a problem is before diving in.

Chapter 05 // Key search filters

🎯 Filters — the real power of Shodan

Raw searches are noisy. Filters turn Shodan into a scalpel.

Filter What it does Example
port:Filter by open portport:3306 (MySQL)
country:2-letter country codecountry:US
org:Organization / ISP nameorg:"Amazon"
hostname:Reverse DNS hostnamehostname:.gov
http.html:Search inside HTML bodyhttp.html:wp-content
http.title:Search page <title> taghttp.title:"Dashboard"
product:Software name from bannerproduct:nginx
version:Software versionproduct:apache version:2.4.49
vuln:Has a specific CVE (paid only)vuln:CVE-2021-44228

Combine filters freely: http.html:wp-content country:US port:443 = all HTTPS WordPress sites in the US. That's your target list built in 2 seconds.

bug bounty uses
Chapter 06 // Bug bounty recon

💰 Shodan for bug bounty hunters

Shodan is a recon multiplier. Here's how hunters actually use it:

🌐 Find WordPress targets

shodan search "http.html:wp-content org:\"Target Corp\""

Then run WPScan on every hit. WordPress + outdated plugins = easy wins.

🚪 Find exposed admin panels

shodan search "http.title:\"Dashboard\" org:\"Target Corp\""

Admin panels on non-standard ports that Burp never found. Bonus points if they have default creds.

🗄️ Expand attack surface

shodan domain target.com shodan host 203.0.113.50

Discover subdomains, related IPs, and services the program scope didn't explicitly mention but didn't exclude either.

🔓 Find exposed databases

shodan search "port:27017 -authentication org:\"Target\""

MongoDB, Elasticsearch, Redis — if auth is missing, that's a critical finding.

Chapter 08 // Ethics

⚖️ The legal line

⚠️ Legal warning: Searching Shodan is legal — it's a public search engine indexing publicly available data. But acting on what you find requires authorization. Connecting to an exposed database you don't own? Illegal. Exploiting a vuln Shodan revealed? Illegal (unless it's in a bug bounty scope). Shodan is a map. Walking into someone's house because the map showed their door was open is still trespassing.
🧠 Brain Power
Shodan shows 50,000 MongoDB databases with no authentication. What can you ethically do with this information?

Ethical options:

  • Report to the org if they have a security contact or bug bounty program
  • Report to CERT/CC or the relevant national CERT for coordinated disclosure
  • Research — publish aggregate statistics ("X% of MongoDB instances are unprotected") without revealing specific IPs
  • Learn — set up your OWN vulnerable MongoDB, find it with Shodan, and practice the full attack chain legally in your own lab

NOT ethical: connecting to any of those 50K databases, downloading their data, "just checking" what's inside, or selling the list. Even with good intentions, unauthorized access is a crime in most jurisdictions (CFAA in the US, Computer Misuse Act in the UK, etc.).
